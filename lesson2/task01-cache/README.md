# Задание 1. Кэшируем зависимости и слои

**Что делаем:** ускоряем пайплайн. Сейчас каждый прогон ставит
pip-зависимости с нуля и собирает образ без кэша.

## Часть А. Кэш pip

У `actions/setup-python` есть встроенный кэш. Найдите в документации
(или вспомните лекцию по CI/CD) параметры `cache` и
`cache-dependency-path` и добавьте их в шаг setup-python так, чтобы
кэш строился по файлу `app/requirements-dev.txt`.

## Часть Б. Кэш Docker-слоёв

Переведите сборку образа на `docker/build-push-action@v6`:
вместо ручного `docker build` используйте связку
`docker/setup-buildx-action@v3` + `docker/build-push-action@v6`
с параметрами:

```yaml
cache-from: type=gha
cache-to: type=gha,mode=max
```

Остальное (теги, build-arg) перенесите в параметры action —
`tags:` и `build-args:`. Пуш пока оставьте ручным шагом или
перенесите в action через `push: true` — решите сами и обоснуйте
в отчёте, почему так лучше.

## Проверка

Запушьте и дождитесь прогона. Затем запушьте ещё один коммит
(например, строчку в README) и сравните время джоб.

## В отчёт

- фрагмент итогового `ci.yml` с кэшами;
- время джобы `docker` до и после (скриншоты логов);
- одно предложение: почему второй прогон быстрее.
