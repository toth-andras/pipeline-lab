# Задание 8. Полный цикл с нуля (зачётное)

**Что делаем:** прогоняем всю цепочку целиком, без подсказок,
как на реальной работе. Задание закрывает лабораторную.

## Сценарий

В компанию пришёл новый разработчик. Ему выдали ваш репозиторий
и сказали: «выкати версию 1.0.0 и задеплой её из release-репозитория».

1. Убедитесь, что пайплайн зелёный на main (lint, test, build,
   Trivy, push, smoke).
2. Выпустите релиз `v1.0.0` (git-тег). Проверьте, что в GHCR
   появились правильные теги, а в Artifactory — закэшированный образ.
3. Проведите образ `1.0.0` через staging в release (task06).
4. Задеплойте из **release**-репозитория. Проверки:
   - `curl localhost:8080/health` → `{"status":"ok"}`;
   - `curl localhost:8080` → версия `1.0.0`;
   - `docker compose -f docker-compose.deploy.yml ps` → контейнер Up.
5. Покажите преподавателю живьём: меняете версию на `1.0.1`,
   вся цепочка проходит без ручной сборки, деплой показывает
   новую версию.

## Чек-лист самопроверки

- [ ] в репозитории нет сломанных/лишних workflow (broken.yml удалён);
- [ ] `.trivyignore` с осмысленным комментарием;
- [ ] пайплайн зелёный по тегу и по ветке;
- [ ] deploy-файл смотрит в release-репозиторий Artifactory;
- [ ] откат к `1.0.0` занимает меньше минуты.

## В отчёт

По одному скриншоту на каждый пункт чек-листа.
