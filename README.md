# Лабораторная: сквозной пайплайн — от коммита до деплоя

**Что делаем:** связываем всё, что изучили раньше (Git, Docker,
CI/CD, Artifactory), в одну рабочую цепочку и добавляем к ней
сканирование уязвимостей:

```
git push → GitHub Actions: lint → test → build → Trivy → push в GHCR
                                                        ↓
                            Artifactory (кэширует GHCR, staging → release)
                                                        ↓
                            docker compose pull → up → smoke-проверка
```

Без Kubernetes: деплоим локально через docker compose.

## Как работать

1. **Занятие 1** — папка `lesson1/`. Занятие вместе с преподавателем:
   он показывает шаг на экране, вы повторяете у себя. К концу
   занятия у каждого должна работать вся цепочка.
2. **Занятие 2** — папка `lesson2/`, задания `task01`…`task08` по порядку.
   Выполняете самостоятельно; после каждого блока преподаватель
   показывает эталонное решение и разбирает типичные ошибки.
3. В заданиях встречаются пропуски `____` и пометки `<ВПИШИТЕ ...>` —
   подставьте свои значения.
4. `templates/` — заготовки и сломанный workflow для задания 4.
5. В конце каждого README — что сдать в отчёт.
6. `slides.html` — презентация с теорией и схемой пайплайна
   (открыть в браузере).

## Подготовка

Нужно заранее:

- аккаунт на GitHub и персональный токен (classic) с правами
  `read:packages`, `write:packages` — создаём на занятии 1, шаг 0;
- Docker (Docker Desktop или colima);
- Python 3.10+ и `make`-подобный терминал;
- jfrog CLI — настроен ещё в artifactory-lab (`jf c show`).

## Про Jenkins

В пайплайне используем GitHub Actions. Аналог того же пайплайна
на Jenkins лежит в `jenkins-demo/` — преподаватель кратко покажет
его в конце занятия 1. Подробно Jenkins разбираем отдельно —
**на семинаре наставника**.

## Что сдаём

Один отчёт: по занятию 1 — скриншоты из шагов, по занятию 2 — артефакты
из каждого задания (см. раздел «В отчёт» в каждом README).
